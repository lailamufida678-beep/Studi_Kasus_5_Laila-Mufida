Baris 1-4 adalah dictionary bernama daftar_kendaraan. Baris 6-14 merupakan program untuk menghitung biaya parkir. Baris 16-18 program akan meminta user(pengguna) untuk memasukkan jenis kendaraan, jam masuk, dan jam keluar. Baris 20-22 adalah proses menghitung lama_parkir dengan cara mengurangi jam keluar dengan jam masuk. Baris terakhir 24-29 fungsinya dalah untuk menghasilkan atau menampilkan ringkasan data parkir ke layar, mulai dari jenis kendaraan, jam masuk-keluar, total lama parkir, hingga total biaya yang harus dibayar.
